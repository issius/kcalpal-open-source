# kCal Pal open-source materials

Public notices and corresponding source for the modified camera component distributed with kCal Pal.

- [Recipient page](https://issius.github.io/kcalpal-open-source/)
- [Third-party notices](third-party-notices.txt)
- [Camera component source ZIP](sources/camera-preview-8.11.6-kcalpal.zip)

The archive contains @capgo/camera-preview 8.11.6, the modified source and patch scripts, MPL 2.0 license, source manifest and reproduction instructions. Individual components retain their respective licenses. The archive's source files correspond to the camera component in kCal Pal 1.0 (57); the same camera modifications were used in build 56.

The rest of the application and backend are not part of this repository. Preserve these versioned downloads when publishing future component revisions.
